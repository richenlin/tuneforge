# 音频质量

本文记录格式转换与音量归一化链路上已经改过的问题，以及还留着的限制。算法定义见 [design.md](design.md) 第 7 节。

## 已修正

| # | 修正前 | 后果 | 现在的行为 |
|---|--------|------|------------|
| 1 | 纯转码（不改声道、不加增益）降位深不做抖动，由 ffmpeg 截断 | 量化失真，小信号更明显 | 降位深走 Rust DSP，使用已有 TPDF 抖动（`dither::quantize_in_place`，误差 ≤ 2 LSB） |
| 2 | 折混按系数和归一化（5.1 除以 3.828） | 只有部分声道有内容时，整体大约掉 11.7 dB | 按 ITU-R BS.775 系数求和；只有真正会削波时，才用一个常数整体缩放 |
| 3 | 折混矩阵把 FL 以 −3 dB 串进右声道；4 声道与 5 声道布局丢掉环绕 | 立体声像变窄，环绕丢失 | 按声道数识别 3/4/5/6/7/8 布局：FL→L、FR→R 不互串；LFE 只在 5.1 / 6.1 / 7.1 丢弃 |
| 4 | 参数与格式都没变也整段重编码 | 无损白做一次，有损多一代损失 | 目标与源一致时用 `-c:a copy` 重封装，音频流比特精确 |
| 5 | 提交输出时先删再 rename；没有拦住「输出路径等于源路径」 | 崩溃窗口里丢掉旧输出；覆盖策略下可能毁掉源文件 | 优先一次 rename，失败再回退；执行前要求输出路径不等于源路径 |

另外两处：

- **重采样用 soxr**：要改采样率时，若构建带 `--enable-libsoxr`（随包的 LGPL 构建带），使用 `aresample=resampler=soxr`，否则回退 `-ar`。
- **无损默认位深等于源位深**：16-bit 源不会被升到 24-bit。这样「16-bit FLAC → FLAC」可以走到比特精确复制。

## 核对过的样本

| 场景 | 结果 |
|------|------|
| 16-bit FLAC → FLAC（参数相同） | 任务标明音频流直接复制。`ffmpeg -map 0:a:0 -c copy -f md5` 下源与输出 MD5 相同（`fef6d692…`） |
| 24-bit 96 kHz → 16-bit FLAC | 标明降位深至 16-bit（TPDF，最大误差 4.52e-5，约 1.5 LSB）。输出为 `flac,96000,2,16`，采样率未改 |
| 5.1 → 立体声 | 源 FL/FR 峰值 −27.1 dB，折混后峰值仍为 −27.1 dB（旧实现对同样素材约 −38.8 dB） |
| 只写标签（M4A / ALAC） | 音频流 MD5 与源相同（`4c81b4df…`），标签写入成功 |
| 上述输出的峰值 | `volumedetect` 均低于 0 dBFS：−21.1 / −21.1 / −27.1 / −21.1 dB |

MD5 只写出前缀，用来对照当时的记录，不是对外的测试向量。

## 尚未处理

- **DSD 超声滤波未接线。** `decode::DecodeOptions.filters` 已有字段，流水线没有把参数传下去。DSD→PCM 目前依赖 ffmpeg 自己的解码。要用真实 DSD 素材听过再决定是否加低通（设计方案 §15 风险 2）。
- **单声道折混的相位抵消。** 左右反相的内容折到 mono 会相消，这是求和的结果。界面有提示。
- **有损到有损仍要再编码。** 参数完全一致时可以比特精确复制；码率或格式一变就必须再编码。
- **取消不能打断正在进行的 ffmpeg 编码。** 取消后丢弃该文件的结果，不改源文件，但要等当前编码结束。
